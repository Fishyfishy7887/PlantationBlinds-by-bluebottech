# PlantationBlinds
DIY Automated Plantation Blinds

## Final XIAO ESP32-C6 / L298N / NEMA 17 conversion

This fork contains one final recommended setup: the visual-layout motor mount, crank arm, vertical linkage, electronics box, renamed clasp parts, XIAO/L298N firmware, and motor test sketch.

Use `BBTArduino_XIAO_L298N.ino` for the MQTT/Home Assistant controller and `BBT_L298N_Motor_Test.ino` for the first bench test. See `XIAO_L298N_WIRING.md` and `BBT_VISUAL_LAYOUT_README.md` for wiring, calibration, and print notes.

## Visual-layout parts

The `BBT_VISUAL_LAYOUT.scad` set matches the illustrated tall frame bracket, electronics box above the NEMA17, exposed crank arm, long vertical linkage, and self-contained clasp parts.
