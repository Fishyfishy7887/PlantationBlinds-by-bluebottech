# Visual-layout actuator parts

This set is shaped to match the exploded/assembled concept diagram:

- `BBT_visual_motor_mount.stl`: tall frame bracket with motor below the electronics-box shelf
- `BBT_visual_crank_arm.stl`: exposed NEMA17 crank arm
- `BBT_visual_linkage_arm.stl`: long vertical linkage arm
- `BBT_visual_parts_box_base.stl`: box for one XIAO ESP32-C6 and one L298N
- `BBT_visual_parts_box_lid.stl`: removable ventilated lid
- `BBT_visual_clasp_A.stl` and `BBT_visual_clasp_B.stl`: renamed original clasp geometry used by this final set

The clasp geometry is retained under the new `BBT_visual_clasp_A/B.stl` names so the final set is self-contained. This is a dimensioned prototype layout for a standard NEMA17 and should be test-fitted before final ASA printing. Start with the crank arm disconnected from the shutter and verify the full vertical movement by hand.
